# DSH Mobile v0.33.0 —— 首个公开测试版

把 DeepSeek Harness 装进 Android 手机。内置 proot + Ubuntu 24.04 + Node 24 + dsh，
全部本地运行，无需 root、无需 Termux。

## 安装

下载下面的 `DSH-Mobile-0.33.0.apk` 直接安装。

- 需要 **Android 10 (API 29)** 及以上，**仅 arm64-v8a**
- APK 约 155 MB（内含完整 Ubuntu 用户态 + Node + dsh）
- 首次启动解包约 1~2 分钟

## ⚠️ 首次进入要等约一分钟

启动后会显示：

> ⟳ 正在准备工作区…

**这是正常的** —— dsh 在后台创建会话，要经过 proot，手机上需要几十秒到一分钟。
等它自己消失，输入框就能直接打字。**期间请不要点输入框**。

## 这一版有什么

- 单栏移动布局 + 浮层抽屉（左缘右滑开 / 抽屉内左滑关）
- dsh 设置面板改整屏，导航变顶部横向标签条
- 原生设置页：主色预设 / 深色模式 / 会话字号 / **界面缩放 70%~120%** / 动效开关
- **工作区由你指定**：安卓原生文件夹选择器，绑定到容器内 `/workspace`
- 亮/暗主题切换带过渡，不再硬切
- 等待遮罩，避免误触那个卡加载的目录选择器

## 已知问题

- 首次进入等待约一分钟（proot 的性能特性，暂未优化）
- 工作区选择需要「所有文件访问」权限
- 摄像头多模态、Skill/MCP 可勾选清单、前台服务保活 尚未实现
- 仅在 vivo V2505A / Android 16 上做过完整验证
